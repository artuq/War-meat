# 🎮 WAR MEAT

> Strzelanka typu roguelite z widokiem z góry, w której grasz żołnierzami posiadającymi wyposażenie oraz bronie jak w Battlefield, walczącymi z hordami przeciwnika.

---

## 📖 One-Pager

### 1. Core Experience (Gwiazda Północna)

**Emocja gracza:** Chęć pokonania wszystkich wrogów, zdobycie poziomów, loot, zwycięstwo.

### 2. Elevator Pitch

Strzelanka typu roguelite z widokiem z góry, w której grasz żołnierzami posiadającymi wyposażenie oraz bronie jak w Battlefield, walczącymi z hordami przeciwnika.

### 3. The Hook (Co nas wyróżnia?)

| Element | Opis |
|---------|------|
| **Mechanika** | Auto-battler, w którym prowadzisz 3–4 postacie naraz |
| **System** | Głęboki system klas, atrybutów oraz statystyka „szczęścia" wpływające na rozgrywkę |
| **Struktura** | Pętla oparta na falach i sklepie, z klimatem misji polegającym na przechodzeniu z punktu A do B |
| **Rozwój** | Zbieranie surowców z wrogów oraz bogaty system ulepszeń między misjami |

### 4. Gameplay Loop (Pętla)

```
Akcja ➜ Nagroda ➜ Progres ➜ Akcja …
```

- **Akcja:** Walka z hordami w formacji oddziału i zbieranie wypadającego lootu.
- **Nagroda:** Waluta i surowce pozwalające na zakupy w sklepie między falami.
- **Progres:** Stałe wzmacnianie statystyk i odblokowywanie nowych klas żołnierzy.

### 5. Czego NIE ROBIMY (Anti-Features)

- [x] **Brak Online** — Gra skupia się wyłącznie na trybie dla pojedynczego gracza.
- [x] **Brak Otwartego Świata** — Stawiamy na zamknięte, intensywne areny i misje liniowe.
- [x] **Brak 3D** — Styl wizualny oparty całkowicie na 2D (pixel art lub sprity).
- [x] **Brak skomplikowanego sterowania** — Rezygnujemy z wirtualnych gałek na rzecz intuicyjnego „tap-to-move".
- [x] **Brak Pay-to-Win** — Rozwój tylko poprzez umiejętności i czas spędzony w grze.

### 6. Referencje (X meets Y)

| Gra | Inspiracja |
|-----|-----------|
| **Brotato** | Mechanika walki i postęp |
| **Cannon Fodder** | Zarządzanie oddziałem i klimat |
| **Battlefield** | System klas i klimat |
